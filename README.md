# Smart Expense Tracker 💰

A web-based expense management application designed to help users track their daily expenses, manage transactions, and monitor their spending in one place.

## 📌 About the Project

Smart Expense Tracker is a personal finance management application that provides a convenient way to record and organize expenses. It helps users maintain expense records, manage financial activities, and get a better understanding of their spending habits.

The application uses a frontend and backend architecture to provide a structured and user-friendly expense management experience.

## ✨ Features

- **Expense Management:** Add, update, view, and delete expense records.
- **Transaction Tracking:** Maintain records of financial transactions.
- **User Authentication:** Secure user access and account management.
- **Expense Organization:** Keep financial records organized.
- **REST API Integration:** Communicate between frontend and backend.
- **Database Management:** Store and retrieve expense information.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project

```bash
cd Smart-Expense-Management-System
```

### 3. Install Dependencies

Install the dependencies in the root, frontend, and backend directories as applicable.

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the appropriate backend directory and configure the required environment variables.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Use the exact variable names expected by your backend code.

### 5. Run the Application

Start the backend and frontend using the scripts defined in their respective `package.json` files.
